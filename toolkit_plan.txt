1. TOOLS I HAVE CHOSEN

Tool 1: Simple Calculator
This tool asks the user for two numbers and an operation, then calculates and displays the answer.

This tool allows the user to add tasks, view tasks, and remove tasks from a list.

Tool 3: Number Guessing Game
This tool asks the user to guess a secret number and gives feedback until the correct number is guessed.
