
# Python Toolkit - Week 8 Assignment

## Project Description

My Python Toolkit is a menu-driven program that provides three useful tools: a simple calculator, a to-do list manager, and a number guessing game. The user selects a tool from the menu, uses it, and returns to the main menu or quits the program.

## Tools Included

- **Simple Calculator:** Performs addition, subtraction, multiplication, and division.
- **To-Do List Manager:** Allows users to add, view, and remove tasks.
- **Number Guessing Game:** Challenges users to guess a secret number between 1 and 10.

## Python Concepts Used

This project uses variables, functions, lists, loops, conditionals, user input, f-strings, exception handling, and list membership checks.

## How to Run the Program

1. Install Python 3 if it is not already installed.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run `python toolkit.py`.
5. Follow the numbered menu to select a tool.

## Reflection

The hardest part of this assignment was connecting the three tools to one main menu while ensuring that the menu returns after each tool finishes. The most challenging bug was making sure invalid inputs did not crash the program. I used conditionals and exception handling to handle unexpected choices and invalid number inputs. Working with the to-do list helped me understand how lists can change while a program is running. I also learned how loops make interactive programs easier to use. If I had one more week, I would add the ability to save tasks to a file so they remain available after the program closes.
